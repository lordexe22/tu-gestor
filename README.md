# Tu Gestor

Una aplicación de escritorio para Windows que agiliza la confección de trámites del automotor.

**Para descargarla: https://lordexe22.github.io/tu-gestor**

La app se actualiza sola: una vez instalada, cada versión nueva le llega al abrirla.

---

Este repositorio tiene sólo la página de descarga (`index.html`, publicada con GitHub Pages) y los instaladores de cada versión (en *Releases*). El
código de la aplicación es privado.
